# Open Waters Online — PRD

## Original problem statement
Persistent browser-based text fishing MMO. Players create a character, fish via an interactive tension-bar encounter, collect hundreds of fish (journal), sell/trade on a player market, upgrade gear, unlock waters, chat, and compete on leaderboards. Classic browser-MMO UI (compact panels, subtle borders, strong typography), no SaaS/glow aesthetic. AI-generated artwork for landing, waters and fish.

## User choices
- Auth: username + password (JWT, Bearer token + httpOnly cookie)
- Minigame: real-time tension bar (hold to reel / release), fish behaviours vary
- Art: Gemini Nano Banana via Emergent key (17 images in /frontend/public/art, jpg)
- Chat: global + trade (5s polling)
- Content: 281 species across 10 waters, 5 rarities, variants (scarred/giant/albino/golden), light lore

## Architecture
- Backend: FastAPI `/app/backend/server.py` (auth, fishing, waters, inventory, journal, shop, market, chat, feed, leaderboards, profiles, seed) + `game_data.py` (fish/waters/gear/bait tables). MongoDB collections: users, catches, journal, listings, trades, feed, chat, pending (encounters), login_attempts.
- Frontend: React + Tailwind, custom classic-MMO CSS (`index.css`). Pages under `src/pages/game/*`, minigame `components/TensionGame.js`, chat `components/ChatPanel.js`, context `context/GameContext.js`.
- Seeded 8 "resident" players (catches, journals, listings, feed, chat) so world feels populated. Password in backend/.env SEED_PASSWORD.

## Core mechanics
- Energy 100, cast costs 2, regen 1/10s. Bite chance 72% + bait bite bonus. Bait luck shifts rarity weights; wrong-water bait works at 1/3.
- Server creates pending encounter (species/weight/variant hidden), returns fight params (strength, erratic, stamina, zone width, recovery, tolerance, time limit). Client plays fight; server validates elapsed time on land.
- Value = rarity base × species mod × size ratio × variant mult. Vendor pays 70%. Market fee 5%. Baitable small fish → 3 Live Bait each.
- Waters unlock by level + one-time gold passage. Gear: 8 rods (power/control), 6 reels (recovery), 6 lines (tolerance), 10 baits.
- XP per level = 80·L^1.55. Titles by level/legendaries.
